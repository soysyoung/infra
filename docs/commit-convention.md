# 커밋 컨벤션

이 저장소는 변경 이력을 빠르게 이해할 수 있도록 Conventional Commits 형식을 사용합니다.

## 기본 형식

```text
<type>: <subject>
```

- `type`은 영문 소문자로 작성합니다.
- `subject`는 변경 내용을 짧고 명확하게 작성합니다.
- 제목 끝에는 마침표를 붙이지 않습니다.
- 한 커밋에는 하나의 목적에 해당하는 변경만 담습니다.

## 타입

| 타입 | 사용 기준 |
| --- | --- |
| `feat` | 새로운 기능이나 실습 내용을 추가할 때 |
| `fix` | 오류를 수정할 때 |
| `docs` | README, 실행 예시 등 문서만 변경할 때 |
| `test` | 테스트를 추가하거나 수정할 때 |
| `refactor` | 동작은 유지하면서 코드를 개선할 때 |
| `style` | 코드 동작과 무관한 형식이나 공백을 수정할 때 |
| `chore` | 설정, 폴더 정리 등 기타 유지보수 작업을 할 때 |

필요한 경우 제목 아래에 빈 줄을 두고 변경 이유나 주의 사항을 본문으로 작성합니다.
