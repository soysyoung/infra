# 0001. WSL 배포판은 Ubuntu 24.04 LTS

- 상태: 채택 (2026-10-23)

## 상황
WSL 에 올릴 배포판을 정해야 한다. WSL 목록에는 22.04, 24.04, 26.04 가 있다.

## 결정
**Ubuntu 24.04 LTS** (`Ubuntu-24.04`).

## 근거
- 표준 보안 지원이 2029년 5월까지라 이 프로젝트 기간에 충분하다 (ubuntu.com 지원 표 기준, 2026-10-26 재확인. 처음에는 4월로 적었다).
- 26.04 는 2026년 4월 출시로 6개월차다. NVIDIA, Docker 등 서드파티 저장소와 문서가 24.04 기준으로 더 검증되어 있다.
- 안정성 우선 원칙: 새 LTS 는 첫 포인트 릴리스 이후 안정화된 뒤에 옮긴다.

## 대안
- Ubuntu 26.04 LTS: 더 오래 지원되지만 위 이유로 보류.
- Ubuntu 22.04: 지원은 남아 있으나 굳이 낮은 버전을 고를 이유가 없다.

## 재검토 시점
26.04 의 NVIDIA/Docker 저장소 지원이 충분히 쌓였을 때, 또는 24.04 가 EOL 에 가까워질 때.
